Tre problemer, ett tillegg

Alt leses som innlogget bruker via Unimicros API. Ingenting bokføres uten Unimicros egen bekreftelse.

Purring med hodet

Åpne fakturaer aldersfordeles og kundene rangeres etter det som faktisk er forfalt: innbetalinger som aldri ble koblet til en faktura trekkes fra først. I demoselskapet lå det 5,3 millioner slik. Neste steg foreslås etter norsk praksis, og ett klikk lager purreteksten med Unimicros egen tekstgenerator.

Likviditet du kan stole på

13-ukers prognose fra banksaldo, åpne kunde- og leverandørfakturaer og faste kostnader. Forutsetningene står i klartekst, og laveste punkt er markert. Penger som allerede er mottatt telles ikke som fremtidig innbetaling.

Revisjonssjekk som forklarer seg

Samme kontroller som Unimicros revisjonssjekk, pluss to egne (umatchede innbetalinger, mva-melding). For hver feil: årsak, hvordan du sjekker, og det balanserte korreksjonsbilaget, i riktig rekkefølge.

Der regnskapsføreren allerede er

Én plugin, fem flater: side under Salg, widget på dashbordet, merkelapp på faktura og kunde, kolonne i fakturalisten. Samme logikk finnes også som MCP-server for Claude og andre AI-assistenter.

    Bonus: mørk modus for Unimicro

    Unimicro har ikke mørk modus, men designsystemet er bygget for det: hver farge er et navngitt token. Vi laget et komplett mørkt tema i samme format som merkevaretemaene for DNB, SpareBank 1, Eika og Azets, kontrastsjekket mot WCAG AA, og en liten nettleserutvidelse med lys/mørk-bryter som viser det live.

    Temaet, kontrastsjekken og utvidelsen · De få stedene appen bruker hardkodede farger er dokumentert som det Unimicro selv må rette.

    Slik er det bygget

    Plugin

    Unimicros plugin-plattform (Lit, native visninger, designsystemets komponenter og tokens). Data via host.api og statistikk-endepunktet. Ingen egen backend.

    Delt domenelogikk

    Aldersfordeling, purretrinn, prognose og revisjonsforklaringer er ren TypeScript med enhetstester, brukt både av pluginen og MCP-serveren.

    MCP-server

    Samme verktøy for Claude og andre assistenter: REST + statistikk, og Unimicros egen MCP for bokføring med bekreftelse.
